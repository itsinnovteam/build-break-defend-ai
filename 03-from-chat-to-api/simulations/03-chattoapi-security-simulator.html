Secure the pipeline

Think of it like... a mailroom for a bank. Nothing sensitive goes out unchecked (redaction), every incoming parcel is treated as possibly dangerous (untrusted data), the clerk may only stamp approved forms (allowlist), and a logbook records what happened without copying the letters (audit).
alert file -> [size limit] -> [redact] -> [injection check] -> [wrap in tags] -> AI (local Ollama) -> [schema + validate] -> [allowlist + policy] -> [clean output] -> card / JSON + exit code -> [audit log]
