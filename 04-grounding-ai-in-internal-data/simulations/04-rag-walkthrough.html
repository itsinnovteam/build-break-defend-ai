Phase 7 - Reflect: write these down

  1. In two sentences: why can RAG retrieval security not depend on instructions given to the LLM?
  2. Name the three v1 flaws (fail open, self-declared role, no filter) and the v2 control that fixes each.
  3. Which of the 9 attacks was prompt injection, which was data residency, and which were authorization?
  4. What would you add before production? (Hint: real SSO tokens, permission sync from the source system, encryption at rest, monitoring of the audit log, a test set run in CI.)
Model answer for 1: The model follows text, and text can be crafted by users or planted in documents. Once a restricted chunk is in the prompt it has already left its access boundary, so access must be decided by trusted code before retrieval.
