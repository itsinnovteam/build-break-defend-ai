LLM Sampling & Temperature Simulator

See how an LLM turns a probability distribution into the next token, and what temperature actually changes about that process.

What is temperature?

A model doesn't just "know" the next word , it scores every possible next token by how likely it is, then picks one. Temperature controls how strongly that choice favors the highest-scoring token. It does not add knowledge, and it does not make the model "think harder"; it only reshapes how much of a chance the lower-probability options get.

An easy way to picture it: each word holds raffle tickets based on how likely it is (that's what the bars below show) ; low temperature means the top word almost always wins the draw; high temperature spreads the tickets out, so long-shots get a real chance too.

How to use this

  1. Move the Temperature slider and watch the bars in Section 2 reshape , no token is chosen yet, this just shows the odds changing.
  2. Switch Sampling Mode to Greedy to see the deterministic baseline: always the top token, no randomness at all.
  3. Click "Sample Next Token" to actually pick one, based on the current odds.
  4. Run it again at the same temperature , at low temperature you'll usually get the same token; at high temperature, expect it to vary.

The prompt below is fixed on purpose. Keeping it constant means the only thing changing between runs is the sampling setting , so any difference you see is caused by temperature, not by a different question.

Security takeaway: temperature controls variability, not truth. A high temperature can make outputs more diverse, but it does not make the model more accurate. For security workflows, keep the distinction between generation behavior and evidence/verification explicit.

Quick mental model

Low temperature: "Prefer the safest/highest-probability choice."

Higher temperature: "Give lower-probability choices more opportunity."

Important: Temperature is applied to the model's scores before sampling. It does not cause the model to "think harder," retrieve new information, or understand the prompt better.
