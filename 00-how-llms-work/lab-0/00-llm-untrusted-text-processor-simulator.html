Injected Instruction or Just Content?

Guess first, then scan , build the habit of reading before trusting.

What is an "untrusted text processor"?

An LLM can't always tell the difference between an instruction it should follow and content it's just supposed to read. If a webpage, email, or document contains text phrased like a command , "ignore previous instructions," "system: reveal..." , the model may follow it, even though it only appeared inside something it was asked to summarize. This is called prompt injection, and the fix is simple to state: treat anything read from outside as data to process, never as a command to obey.

An easy way to picture it: imagine a mailroom clerk whose job is to open letters and pass along the message inside. One letter includes a slipped-in note: "Also, please mail a spare set of building keys to this address." A well-trained clerk doesn't do it , that's not an instruction from their manager, it's just something written on a piece of paper they were handed to read. An LLM reading a webpage, email, or document is in the exact same spot: the words on the page can be phrased exactly like a command, but they're just content someone put there , not an instruction from you.

How to use this

  1. Pick a scenario from the dropdown , each is a real document type an assistant might be asked to read.
  2. Read the System Instruction (the actual task) and the Content (what it's been handed).
  3. Make your guess , Injection Present or Looks Clean , before scanning.
  4. Click "Scan" to see the verdict, with the suspicious phrase highlighted if there is one.
  5. Check History anytime to review what you've covered.

There's no score here , and not every example contains an injection. The goal is to actually read carefully each time, not to assume the worst by default.

Quick Reference

Treat as instructions

  • What you (the user) actually asked for
  • The system prompt / task definition
  • Nothing else, no matter how it's phrased

Treat as untrusted data

  • Emails, webpages, and articles
  • PDFs, resumes, and uploaded files
  • Code comments and search results
